# Intro to Python project

This project focuses on cleaning, organizing, and analyzing data using Python and Pandas.

## What is inside this project:
* **Data/**: Contains our final, cleaned, and perfect Excel data sheet.
* **Notebooks/**: Contains the Python code used to process the files.

## Summary of Processes:
1. **Cart.ipynb**: Cleaned complex, nested JSON data, fixed column names, and successfully exported everything into a clean Excel spreadsheet.
2. **product.ipynb**: Cleaned and organized the product catalog data. Finally exported it to CSV
3. **Stock Exchange (1).ipynb**: exported to CSV.

## How to use:
Make sure you have `pandas` and `openpyxl` installed in Python to run these notebooks.
